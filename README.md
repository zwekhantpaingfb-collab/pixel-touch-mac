# Pixel Touch — Mac installer

Terminal ကနေ တစ်ကြောင်းတည်းနဲ့ ထည့်သွင်းပါ (Apple Silicon Mac, macOS 14+):

```
curl -fsSL https://pixel-touch-license.web.app/mac | bash
```

(သို့)

```
curl -fsSL https://raw.githubusercontent.com/zwekhantpaingfb-collab/pixel-touch-mac/main/install.sh | bash
```

ဖယ်ရှားချင်ရင်:

```
curl -fsSL https://pixel-touch-license.web.app/mac | bash -s uninstall
```
